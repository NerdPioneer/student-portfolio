Security Operations · Python · WGU · 2025

Security Log Analysis and Incident Response Tool

Problem

Security event data arrives from several sources in inconsistent formats, which slows investigation.

Approach

A Python parser that ingests logs, normalizes timestamps into a single timeline, and extracts indicators of compromise: IP addresses, domains, file hashes and usernames.

Outcome

A chronological, SIEM-ready view of an incident, validated against sample datasets, with edge cases and limitations documented.

Python Log Parsing IOC Extraction SIEM

Secure Remote Access · AWS · Lab · 2022

AWS Client VPN with Directory Authentication

Problem

Remote users need encrypted access to private cloud resources without exposing those resources to the internet.

Approach

A Client VPN endpoint with certificate-based TLS authentication, Active Directory for identity, and scoped routes and security groups.

Outcome

A tested, encrypted remote-access path in which every connection is tied to a verified identity.

AWS Client VPN VPC Active Directory PKI
